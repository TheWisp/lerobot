# Stories

Design docs for work that **does not exist yet**.

`gui/docs/` describes the GUI as built. Everything in `gui/docs/stories/` is a
proposal: the shape of a feature, the decisions still open, and the phases it
would ship in. Nothing here is a claim about current behaviour, so a reader who
lands on one of these files by accident cannot mistake a plan for a description.

A story graduates when its first phase lands: move it up to `gui/docs/`, re-tense
it to describe what shipped, and leave the unbuilt phases behind as their own
story (or as `TODO.md` bullets if what remains is small).

`TODO.md` stays the source of truth for status — stories hold the design, the
checkboxes live in the TODO section that points here.
