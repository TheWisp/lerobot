# Robots that predate this check and still ignore the ActionChunk half of
# Robot.send_action's contract. Every one of these raises AttributeError if a
# chunk-sending policy is pointed at it — the same failure HVLA S1 hit on
# OpenArm2, which is what prompted the rule.
#
# They are listed rather than fixed because they are upstream-owned drivers:
# editing a dozen of them is rebase conflict surface for a defect that only
# fires on a path nobody currently runs them on. Fix one when someone drives it
# with a chunk-sending policy, and delete its line.
#
# This list may only ever get SHORTER. A new robot cannot be added to it
# without a deliberate edit here, which is the point — the failure was silent
# precisely because nothing recorded who was and was not honouring the contract.
