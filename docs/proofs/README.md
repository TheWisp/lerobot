# Proofs

Captured evidence: screenshots, recordings and transcripts of what a change was
observed to do, kept so a claim in a pull request stays checkable after the pull
request scrolls away.

Nothing here is a design document. These files record what happened, not what
should happen, and they are not maintained against the code — a proof describes
the revision it was captured on. Design decisions and invariants live beside the
code they describe.

One directory per subject. Where it carries an index naming what its files
show, that index is `EVIDENCE.md` — not `README.md`, which is what made these
read as design documents in the first place.
