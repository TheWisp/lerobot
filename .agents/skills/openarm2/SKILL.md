# OpenArm2

Read [references/openarm2-sources.md](references/openarm2-sources.md) for
official OpenArm 2.0 documentation and links to this repository's Damiao and
OpenArm integration.

For CAN setup or a missing/unresponsive motor, read
[references/can-diagnostics.md](references/can-diagnostics.md) before sending
commands or changing interface or motor configuration.

Treat the current configuration and source as authoritative. Do not preserve
dataset IDs, feature counts, camera names or resolutions, motor IDs, or CAN
interface names as permanent OpenArm2 facts.
